Oś transferubrak danych
——
Zakres widoczności?

WorkRouter widzi metadane transportu: jawny DNS oraz adres IP:port. Przy zgodnym źródle może też rozpoznać HTTP Host lub TLS SNI. Nie widzi pełnych URL-i ani treści HTTPS.

  • DoH/ECH może ukryć nazwę domeny.
  • QUIC/HTTP‑3 ogranicza klasyfikację.
  • VPN może ukryć cel przed hostem.
  • Brak MITM i inspekcji payloadu.
Ograniczona widoczność: —Pauzowanie przechwytywania: niedostępne.
