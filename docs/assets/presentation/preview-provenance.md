# Interface preview

Podgląd prawdziwego interfejsu z jawnie oznaczonymi danymi przykładowymi. Nie uruchomiono usługi Windows, WFP, NAT ani testu izolacji sieci.

Captured at 1440 × 1000 using Chromium against the repository source on localhost.
No private user files, session cookies or device logs were used.

The fixture is versioned in `preview-data.json`. A visible banner identifies it in the screenshot.
