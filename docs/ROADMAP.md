# Roadmapa

## Stan bieżący

Linia `0.1.x` obejmuje lokalny panel operatorski, usługę Windows, Mobile Hotspot/ICS, WFP, SMB, watchdog, diagnostykę i ulotne metadane ruchu. Build, testy core i pakietowanie są automatyzowalne; akceptacja fizyczna pozostaje zależna od sprzętu.

## Następne etapy

1. Powtarzalna akceptacja Windows 11 na reprezentatywnych adapterach Wi‑Fi i wariantach ICS.
2. Macierz zachowania z firmowymi VPN/EDR oraz dokumentacja ograniczeń.
3. Ewentualna silniejsza izolacja klientów WORK, tylko po potwierdzeniu możliwości backendu.
4. Zaufany Authenticode dla EXE/MSI; podpisane tagi, SPDX SBOM oraz weryfikowalna proweniencja GitHub/Sigstore są już częścią procesu wydań.
5. Przegląd prywatności przed jakąkolwiek trwałą, szyfrowaną i opt‑in telemetrią.
6. Rozszerzenie kontraktów API i dokumentacji operacyjnej bez obiecywania pełnego wglądu w HTTPS.

Roadmapa nie zawiera terminów ani gwarancji funkcji. Każdy etap wymaga osobnego dowodu i zgody właściciela środowiska.
